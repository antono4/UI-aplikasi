# UI Aplikasi 🎨

![UI Components Banner](https://images.unsplash.com/photo-1561070791-2526d30994b5?w=800)

Beautiful and modern UI components and application designs.

## ✨ Features

- 🎨 Modern UI components
- 📱 Mobile-first design
- 🌙 Dark mode support
- ♿ Accessibility friendly
- 🔧 Customizable themes

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/antono4/UI-aplikasi.git

# Open in browser
cd UI-aplikasi
open index.html
```

```
UI-aplikasi/

└── assets/         # Static assets
```
